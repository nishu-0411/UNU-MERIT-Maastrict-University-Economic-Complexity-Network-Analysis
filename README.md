# Economic Complexity & Network Analysis

This repository contains a Python-based analysis of **Economic Complexity and International Trade Networks**, exploring how countries' productive capabilities and export structures can be represented and analyzed using data-driven methods.

## 📌 Overview

Economic Complexity provides a framework for understanding the capabilities embedded within an economy by examining the products and services it is able to produce competitively.

This project combines **economic complexity analysis** with **network analysis** to study relationships between countries, products, and trade patterns.

## 🎯 Objectives

* Analyze international trade and export structures using Python.
* Explore relationships between countries and exported products.
* Apply concepts from **Economic Complexity** to quantify productive capabilities.
* Construct and analyze country–product networks.
* Identify patterns and structures within international trade networks.
* Visualize economic relationships using data-driven network techniques.

## 📈 Key Concepts

### Economic Complexity Index (ECI)

The ECI provides a quantitative approach to measuring the complexity of an economy based on the diversity and sophistication of the products associated with it.

### Product Complexity Index (PCI)

PCI captures the relative complexity of products based on the characteristics of the countries that are able to produce and export them competitively.

### Revealed Comparative Advantage (RCA)

RCA is used to identify products in which a country demonstrates a relative specialization in exports.

### Network Analysis

Network analysis is used to represent relationships between countries and products, allowing trade structures and patterns to be examined as interconnected systems.
